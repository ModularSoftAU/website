# Welcome to Anchorlight Development

Welcome to the official documentation hub for **Anchorlight Development** — a collective of passionate developers building purposeful software for gaming communities, faith platforms, and beyond.

Here you'll find guides, API references, and configuration docs for all of our products.

## Our Projects

Explore the tools we've built and actively maintain:

### [Zander](./products/zander)
A comprehensive Discord and server administration suite. Manage ranks, announcements, applications, and community moderation from one integrated platform.

### [Player Head Hunt](./products/playerHeadHunt)
A Minecraft plugin for creative, configurable hide-and-seek and scavenger hunt experiences.

### [Craftify](./products/craftify)
A Minecraft datapack that revamps crafting mechanics with new recipes, rebalanced resources, and expanded gameplay depth.

### [DevoteMe](./products/devoteMe)
A spiritual platform connecting people to the Gospel through daily devotions, verse of the day, and Discord integration.
